# Changelog

All notable changes to this integration are documented in this file. The format
follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project
uses [semantic versioning](https://semver.org/).

Describe each change under `## [Unreleased]` as you make it. The Release
workflow moves that section under the version it ships, and the section becomes
the notes of the version's GitHub Release.

## [Unreleased]

### Added

- A linkding device: server online, bookmarks, unread and archived bookmarks,
  the title of the newest bookmark and the linkding version, read every 5 to
  60 minutes (15 by default).
- Optional filters (a tag, a search) for the counters, the widget, the trigger
  and the reading action.
- A dashboard widget: the counters and the newest unread bookmarks, or the
  newest of all.
- The **New bookmark** scene trigger (imports and the bookmarks saved by the
  integration excepted).
- The **Add a bookmark to linkding** scene action, off until allowed in the
  configuration (a link already saved is never changed), and **Read the latest
  linkding bookmarks**.
- **Test the connection**; texts and documentation in English, French, German
  and Spanish.
